ChangeVision 2026 - Analysis Edition
===================================
- Python واحد فقط: 3.11.x 64-bit.
- لا ArcPy، لا ArcGIS Python، لا QGIS Python.
- GIS Tools داخل البرنامج باستخدام Rasterio/PyProj/Shapely.
- إصلاح قراءة GeoTIFF الكبيرة ومسار CRS/Pixel Size.
- دعم aux.xml وtfw كـ sidecars.
- Preflight للتداخل الجغرافي.
- Crop Overlap كامل الدقة.
- Align to Reference كامل الشبكة.
- تقارير وتصدير Analysis فقط.
- ملفات ArcGIS غير موجودة داخل الحزمة.

2026-09-06 — استكمال واجهة الفحص والمعالجة المتسلسلة
- ترتيب الخطوات مع BEFORE / AFTER / CHANGE MAP ومزامنة جغرافية من أي شاشة، 100% وCenter وFull View.
- فحص Metadata والتداخل والحزم وBit Depth والمواءمة والإضاءة وNoData قبل READY؛ منع المقارنة قبل الجاهزية.
- لا يُستنتج CRS أو نوع الحزمة المفردة من اسم الملف أو Gray الافتراضي؛ يوجد تعريف حزم يدوي موثق داخل المشروع.
- توحيد الحزم واستخراج RGB وIntensity وتطبيع اختلاف عمق البت في نسخ تحليل جديدة مع المحافظة على الشبكة والأقنعة.
- RGB ↔ NIR يستخدم أوصاف التدرج البنيوي متعددة المقاييس، مع حجب Raw Pixel Difference وRadiometric العادي؛ النتائج مرشحات للمراجعة.
- زر تنفيذ المعالجات المطلوبة بالتسلسل ينفذ المراحل اللازمة فقط، ويتوقف عند READY أو فشل الجودة أو قرار Radiometric اليدوي.
- الاحتفاظ بإصلاح YCBCR وملفات GeoTIFF السليمة، والمواءمة الحالية، وفحص الإضاءة، والتقارير وحفظ/فتح المشروع.
- أدوات متقدمة، إيقاف تعاوني، رجوع خطوة، مراجعة واستبعاد نتيجة دون تغيير الصور الأصلية.
- تفاصيل التحقق وحدوده في WORKFLOW_VALIDATION_AR.md وvalidation/workflow_audit.json.
